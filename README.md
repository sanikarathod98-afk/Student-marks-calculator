# Student Management & CGPA Dashboard
A python based student management systen built using streamlit and SQLite.

## Features
-Add students
-View students
-Delete students
-Add subject marks
-Calculate grades
-Calculate SGPA
-Student performance Dashboard
-SGPA visualisation
-SQLite database
-calculation
